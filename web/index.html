    How it works

    1. Domain

    The scheme, www., port and path are removed. Only the hostname is kept, for example kapitalbank-az-onlayn-giris.top.

    2. Character n-grams

    The hostname is split into all pieces of 2 to 5 characters (ka, .top, bank- …) and each piece gets a TF-IDF weight.

    3. Logistic regression

    A linear model trained on 219k labelled domains adds up the weights and turns the score into a probability with the sigmoid function.

    Test accuracy 88.0%, ROC-AUC 0.923 on 43.8k unseen domains (PhiUSIIL dataset). The model runs fully in your browser. Known limitation: phishing pages hosted on big platforms like docs.google.com cannot be told apart by the domain alone.
